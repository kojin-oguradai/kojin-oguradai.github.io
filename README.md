# 興人小倉台自治会 ホームページ

GitHub Pages（Jekyll）で公開している自治会ホームページです。
このファイルは **ホームページを更新する役員向けの手順書** です（サイトには表示されません）。

---

## お知らせを追加する（いちばんよく使う作業）

1. GitHub でこのリポジトリを開き、`_posts` フォルダをクリックします。
2. 右上の **Add file → Create new file** を押します。
3. ファイル名を次の形で入力します（**半角英数字**）。

   ```
   2026-06-01-kairan-6gatsu.md
   ```

   - 先頭の `年-月-日` が **掲載日** になります（必ず `0` を付けて2桁で：`06`、`01`）。
   - 日付の後ろは英数字とハイフンで自由に付けます（記事のURLになります）。
   - 最後は必ず `.md` にします。

4. 本文の欄に、次のひな形をコピーして書き換えます。

   ```markdown
   ---
   title: 【回覧】6月の回覧板について
   type: 回覧板
   ---

   ここに1段落目を書きます。この段落がトップページのカードに「あらすじ」として表示されます。

   2段落目以降は、空行をはさんで続けて書きます。

   ## 詳細

   - **日時**：2026年6月10日（水）午前10:00〜
   - **場所**：興人小倉台集会所
   - **持ち物**：筆記用具

   [回覧板のPDFを見る（Google ドライブ）](https://drive.google.com/ここにリンク)
   ```

5. 画面下（または右上）の **Commit changes** を押し、「6月の回覧板を追加」のようにひとこと書いて保存します。
6. **1〜2分ほど** でサイトに反映されます。進み具合は **Actions** タブで確認できます（緑のチェックで完了）。

### `type:`（種類）に書けるもの

| 書く文字 | カードの表示 |
|---|---|
| `重要` | 赤いラベル「重要」 |
| `お知らせ` | 緑のラベル「お知らせ」 |
| `回覧板` | 青いラベル「回覧」 |
| `行事` | 黄色いラベル「イベント」 |

種類を増やしたいときは `_data/news_types.yml` を編集します。

### 書き方のルール（Markdown）

| やりたいこと | 書き方 |
|---|---|
| 段落を分ける | 空行を1行入れる |
| 見出し | 行の先頭に `## ` |
| 箇条書き | 行の先頭に `- ` |
| 太字 | `**太字**` |
| リンク | `[表示する文字](https://～)` |

### 注意

- 先頭の `---` で囲まれた部分は消さないでください。`title:` や `type:` の後ろには **半角スペース** が必要です。
- `sample: true` の行がある記事は「サンプル」として表示されます（作成中の例文用）。本物の記事には書かないでください。
- **未来の日付のファイルは表示されません。** 掲載したい日以降に追加してください。
- **個人の氏名・住所・電話番号、人物が写った写真は載せないでください。** 一度保存すると、削除しても履歴に残ります。
- PDF や写真は Google ドライブ（自治会アカウント）に置き、リンクを貼ってください。

## お知らせを修正・削除する

- **修正**：`_posts` フォルダで対象ファイルを開き、右上の ✏️（鉛筆）から編集して **Commit changes**。
- **削除**：対象ファイルを開き、右上の「…」→ **Delete file** → **Commit changes**。
- **元に戻す**：**Commits** の画面から過去の内容を確認できます。困ったときは担当者に相談してください。

---

## 反映されないときは

1. **Actions** タブを見て、赤い ✕ になっていないか確認します。✕ の場合は、直前に編集したファイルの書き方（特に先頭の `---` 部分）を見直してください。
2. ブラウザで **Ctrl + F5**（スマホは再読み込み）を押してください。
3. ファイル名の日付が未来になっていないか確認してください。

## ファイル構成（管理者向け）

| ファイル / フォルダ | 内容 |
|---|---|
| `_posts/` | お知らせ記事（1件＝1ファイル） |
| `index.html` | トップページ（集会所、規則、お問い合わせ など） |
| `news/index.html` | お知らせ一覧ページ |
| `_layouts/default.html` | 全ページ共通のヘッダー・フッター |
| `_layouts/post.html` | お知らせ記事ページの見た目 |
| `_includes/` | お知らせカード・絞り込みボタンの部品 |
| `_data/news_types.yml` | お知らせの種類の一覧 |
| `_config.yml` | サイト全体の設定（サイト名、URLなど） |
| `style.css` / `script.js` | デザインと動き |
| `assets/images/` | サイトで使う画像（ロゴ、トップ画像など） |
